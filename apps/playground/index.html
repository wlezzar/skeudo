See what code touches before reading how it works.

Skeudo is pseudocode for code review. Write the logic in plain words, and tag every read, write and failure. The tags line up in a column, so a reviewer checks the effects first.

Plain text, in Markdown

A sketch is a ```skeudo fence in a pull request, a design doc or a README. It diffs in git and reads fine before it's rendered.

Written by your agent

The agent skill sketches a function, a commit or a pull request, so a review starts from what the change touches.

Rendered where you read

In VS Code's Markdown preview, on VitePress and Docusaurus sites, or as a page the CLI writes for you to send.

::the code view

Loose about logic, strict about effects.

Write each step in whatever words make it clear. Each read, write or failure gets a tag at the end of its line, and a note can say how: a lookup by key, a full scan, a time to live.

Names carry their labels, so untrusted input and secrets stay marked wherever they go.

::the data view

A data model, told as a story.

Declare a few tables, then say what happens. Each step adds, changes or removes rows, and the reader steps through it: new rows in green, changed cells in blue.

Click a step, or click the sketch and use the arrow keys. Edit it in the playground →

::get started

Use it where you already work.

Have your agent write sketches

Install the skill, then ask your agent to “sketch this pull request”. It works with Claude Code and the other agents the skills CLI supports.

npx skills add wlezzar/skeudo

Check and share from the terminal

skeudo check reports mistakes in a sketch, and skeudo render turns a Markdown file into a page you can send.

npm install -g skeudo

Show sketches on a docs site

markdown-it-skeudo for VitePress and other markdown-it sites, remark-skeudo for Docusaurus, Astro and MDX.

npm install remark-skeudo

Read sketches in VS Code

The extension highlights sketches and renders them in the Markdown preview, and opens their source links in your copy of the repository.

code --install-extension wlezzar.skeudo-vscode

Building your own tool? @skeudo/core parses sketches, and @skeudo/html renders them.
